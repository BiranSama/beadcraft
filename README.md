# 豆图工坊 · BeadCraft

**让图片成为可以一颗颗摆出来的拼豆图纸。**

BeadCraft 正在开发，目标是提供从图片到拼豆图纸的本地工作流：选图、选色、编辑、检查连接，再照着图纸制作。

> 当前已提供可独立构建和测试的数据模块；暂无可使用的应用界面、安装包或在线演示。

## 计划方向

- **图片转图纸**：选择尺寸与实际豆色，生成清晰的网格和颜色编号。
- **可编辑、可检查**：调整细节，识别孤立部分与连接风险。
- **辅助制作**：查看位置、颜色和用豆数量，逐格完成作品。
- **本地优先**：以本地图片处理为基础，减少不必要的数据上传。

以上均为开发目标，不代表已经实现。连接检查也不能替代材料与实际熨烫验证。

## 使用状态

需要 Node.js 22.16+ 和 npm：

```sh
git clone https://github.com/BiranSama/beadcraft.git
cd beadcraft/domain
npm ci
npm test
npm run typecheck
```

数据模块已实现规范网格、物料快照、项目结构与语义校验、旧 Pindo v1 数据迁移和修订命令校验。只有 0 表示无豆，白豆与透明豆保留独立物料身份；迁移不会读写旧文件。调用示例与限制见 [模块说明](domain/README.md)。

图片转换、编辑/撤销、保存与导出界面尚未接入这些新合同。当前演示色表是合成测试数据，不代表厂商色卡。项目尚未选定开源许可证，代码暂标记为 UNLICENSED；第三方依赖许可见模块说明。

计划先完成 Web 核心，再逐步验证移动端和桌面端。
